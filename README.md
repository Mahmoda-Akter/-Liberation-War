# 📖 Project Overview

Liberation War Archive is a historical digital archive website developed to preserve and showcase important resources related to the Bangladesh Liberation War.

The platform allows users to explore historical documents, freedom fighter interviews, photographs, videos, and submit valuable information through the contact system.

The main goal of this project is to create a clean, accessible, and responsive archive platform using modern frontend technologies.
